# 🏋️ AppFitness

Aplicación móvil de gestión de perfil y métricas de fitness desarrollada para dispositivos Android. El proyecto está diseñado para permitir a los usuarios registrar y visualizar sus datos físicos, objetivos y nivel de actividad de forma sencilla e intuitiva.

Este repositorio contiene **dos ramas principales** que representan dos enfoques de desarrollo distintos: una base funcional y una versión con la interfaz de usuario rediseñada y modernizada.

---

## 📌 Descripción del Proyecto

**AppFitness** es una aplicación que centraliza la información clave de un usuario para su seguimiento deportivo. A través de una pantalla de perfil, el usuario puede consultar y editar sus métricas personales, así como definir sus metas de entrenamiento.

El proyecto nace como una solución básica y evoluciona hacia una experiencia de usuario mucho más pulida, demostrando la capacidad de iterar sobre un producto para mejorar tanto la usabilidad como la estética.

---

## ✨ Características Principales

- **Perfil de Usuario:** Visualización de datos personales como nombre, correo electrónico y avatar.
- **Métricas Físicas:** Registro y consulta de edad, género, altura y peso.
- **Objetivos:** Definición del objetivo principal del usuario (ej. *Ganar masa muscular*).
- **Nivel de Actividad:** Clasificación del nivel de actividad física (ej. *Moderado*, *Intens*).
- **Edición de Perfil:** Acceso rápido a la edición de los datos mediante un botón de edición.
- **Dos Experiencias de UI:** Una versión funcional y otra con un diseño visual avanzado.

---

## 🌿 Ramas del Repositorio

El repositorio está organizado en dos ramas que reflejan la evolución del proyecto:

| Rama | Descripción |
| :--- | :--- |
| **`Basica`** | Contiene la implementación inicial de la aplicación. Se centra en la funcionalidad y en una interfaz sencilla y limpia (tema claro). Es el punto de partida del proyecto. |
| **`UI editada`** | Contiene la versión con la interfaz de usuario completamente rediseñada. Incluye un tema oscuro, tarjetas con iconos para las métricas, una jerarquía visual mejorada y una estética mucho más moderna y atractiva. |
